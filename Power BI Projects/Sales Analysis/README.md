# Sales Analysis – Power BI

## 📊 Project Overview

Developed an interactive **Sales Analysis Dashboard using Microsoft Power BI** to analyze sales performance and generate meaningful business insights.

The dashboard transforms sales data into interactive visualizations and key performance indicators to support business performance monitoring and decision-making.

## 🛠️ Tools & Skills

* Microsoft Power BI
* Power Query
* Data Cleaning
* Data Analysis
* Data Visualization
* Dashboard Development
* Business Intelligence

## 📈 Analysis Areas

The dashboard focuses on:

* Overall Sales Performance
* Revenue Analysis
* Product Performance
* Category Analysis
* Regional Performance
* Sales Trends
* Key Performance Indicators

## 💡 Key Insights

* Analyzed overall sales performance using interactive KPI metrics.
* Compared sales performance across different products and categories.
* Evaluated regional sales performance to identify stronger-performing areas.
* Used interactive visualizations to identify sales trends and business patterns.
* Created a centralized dashboard for easier sales performance monitoring.
