# 💰 Personal Finance & Expense Analytics Dashboard

An interactive **Personal Finance & Expense Analytics Dashboard** built using **Microsoft Excel** to analyze income, expenses, savings, and spending behavior.

The project transforms raw financial data into meaningful visual insights using **Excel Tables, Pivot Tables, calculated fields, and interactive charts**.

---

## 📊 Project Overview

Managing personal finances requires understanding where income goes, how much is spent, and how effectively money is saved.

This project focuses on analyzing:

* 💵 Income patterns
* 💸 Expense distribution
* 🏦 Actual vs Desired Savings
* 📈 Savings Rate
* 🏠 Major expense categories
* 👥 Savings behavior
* 🌍 Tier-wise financial performance
* 💼 Occupation-wise financial patterns

The dashboard provides a simple and interactive way to understand financial behavior and identify major spending and savings patterns.

## 📈 Key Insights

### 💰 Savings Analysis

* The overall average savings rate is **25.51%**.
* **37%** of individuals fall under the **Good Savings** category.
* Actual savings are consistently higher than the desired savings level across occupations.

### 💸 Expense Analysis

* **Rent and Groceries** are the major expense drivers.
* **Tier 1** records the highest average expenses.
* **Tier 3** records the lowest average expenses.

### 🌍 Tier-wise Analysis

* **Tier 3** records the highest average income.
* Tier 3 also records the highest actual savings.
* Despite having the highest income, Tier 3 maintains the lowest average expenses.

### 💼 Occupation-wise Analysis

* Savings performance varies across different occupations.
* Actual savings remain above desired savings across the analyzed occupations.

## 🧮 Key Calculations

### Total Expenses

```text
Rent
+ Loan Repayment
+ Insurance
+ Groceries
+ Transport
+ Eating Out
+ Entertainment
+ Utilities
+ Healthcare
+ Education
+ Miscellaneous
```

### Savings

```text
Income - Total Expenses
```

### Savings Rate

```text
Savings / Income × 100
```

These calculations help evaluate individual financial performance and spending efficiency.
